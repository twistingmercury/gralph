Usage of gralph:
      --agent-arg stringArray   Agent argument; may be repeated to preserve argument boundaries and order
      --agent-exec string       Required unless --agent-profile is set. Agent executable path or name
      --agent-profile string    Optional verified agent profile; explicit agent flags override its command values
  -i, --iterations int          Maximum attempts per checklist item before it is abandoned (default 10)
      --prd string              Required. Path to the PRD.md checklist file that drives the loop
      --progress string         Optional. Path to the progress log file (default: <prd dir>/progress.txt)
      --prompt string           Required. Path to the PROMPT.md template passed to the agent each iteration
      --prompt-mode string      Prompt transport mode: stdin or arg (default "stdin")
      --version                 Show the current version of gralph
